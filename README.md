# Путеводник по играм

Вбиваешь название игры и сразу видишь, стоит ли она твоего вечера.

**Демо:** https://artemglebov654-lang.github.io/game-guide/

## Что на карточке
- время прохождения: сюжет, 100% и сколько это вечеров по 2 часа
- настроение: напряжение, тяжесть, темп, сложность
- кому зайдёт, а кому нет
- похожие игры по ощущению, а не по жанру

## Статус
В базе 8 игр с подробными авторскими карточками и ещё 64 популярные игры с заметками
(о чём, время и настроение, «кому зайдёт»). Остальные игры ищутся через RAWG API.
Есть подбор игры за 7 вопросов (пять результатов с процентом совпадения), личная полка, раздел «Новинки», русские названия в поиске,
светлая и тёмная темы.
Дальше: цены и скидки, больше авторских заметок.

## Как это устроено
- `data.json` и страницы `g/<id>/` (превью ссылок в мессенджерах) каждую ночь собирает GitHub Actions
  (`scripts/build-data.mjs`, `scripts/build-pages.mjs`), чтобы сайт тратил меньше лимита RAWG.

## Запуск
Открой `index.html` в браузере. Сборка не нужна.

## Дизайн
Чёрно-белая журнальная вёрстка (тёмная и светлая темы): крупный логотип, номерные подписи,
тонкие линии, анимации без внешних библиотек.

## Источник данных
Данные и изображения: [RAWG](https://rawg.io).
